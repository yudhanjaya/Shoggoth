Heavy on the cosmos. Light on your machine!

Shoggoth runs AI models on your own Linux computer. Chat with them, or let one work in a folder while you watch. One download sets it up.

Download for Linux Version 5.0. AppImage, x86_64, MIT licence.

Pick a model, or bring your own engine.

llama.cpp, set up for you

Shoggoth downloads the llama.cpp build that fits your graphics card (CUDA, Vulkan or CPU) and keeps it updated. There is nothing to compile and no flags to learn.

The Models page always shows a hand-picked list: unsloth and bartowski quantisations chosen for small, medium and large machines. Each one carries a fit badge, based on a memory estimate that lands within 10% of what llama.cpp really uses. Or search Hugging Face.

The engine you already run

Shoggoth looks for more than 20 local engines on any port, including Ollama, vLLM, SGLang, LM Studio, Strata and Maya, and connects to one with a click. If it misses yours, add it by hand and teach Shoggoth to recognise it.

Hosted services are there when you want them: OpenRouter, Nous Portal, OpenCode, Command Code and Google Gemini. Each is marked as leaving your computer. Switch between any of them from the chat bar or the Models page.

What it does

Chat
Ask questions, paste a picture, switch models mid-conversation.
Work in a folder
Pick a folder. The model reads, searches, edits and runs things there, and asks before it changes anything. Common file types open in chat.
Jobs
Describe a bigger task and how to tell it is done, such as a passing test. It runs round after round in the background. You review the changes before they touch your folder.
Diagrams and documents
Ask for a picture or a README, and it appears in the chat. Curated packages add documents, spreadsheets and subagents.
Skills it writes itself
A skill is a short instruction sheet that makes small models more dependable. The model can write new ones from what it learns, and you approve each.
Speech
Talk to it with whisper.cpp. Optionally, have it read answers aloud with Bark.

One Shoggoth serves. The laptops find it.

Switch on sharing on the machine with the big graphics card. Other Shoggoths on the network see it and ask to pair.

  1. The server shows a six-digit code and the name of the laptop asking.
  2. You type the code on the laptop. Nobody copies an API key.
  3. The laptop uses the server's models over an encrypted link.

The model runs on the server. Your chats, the agent and your files stay on the laptop. Remove a laptop from the server's list and its access ends.

Your chats stay on your computer.

What stays local

Chats, files, skills and settings live in ~/.config/shoggoth and ~/.local/share/shoggoth. Models run on your hardware. The agent starts with telemetry and update checks turned off. On a home network, other Shoggoths reach yours only after you pair them, and only over an encrypted link.

What leaves, and when

  • Web search. Only if you allow it. The model shows the exact words and waits for a yes. You can switch it off for good.
  • Hosted services. Only if you connect one. It is marked as leaving your computer, and your chat goes to that service.
  • Downloads. Models from Hugging Face, llama.cpp and Shoggoth updates from GitHub. The automatic update check has a switch.

Get Shoggoth.

Download the AppImage, make it executable, run it. The Getting ready screen does the rest. You need Linux on x86_64 and internet for the first-run downloads.
