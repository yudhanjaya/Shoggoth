Watch your graphics memory fill as models load. If you have more than one card, choose which ones Zest uses and in what order. Changes apply the next time a model loads.

Engine

An engine is the program that actually runs a model, and each kind of model needs its own: one for chat, one for turning speech into text, one for pictures, and so on. Each engine can run on different hardware, called a backend. Pick the one you want, or install one that's missing. Changes apply the next time a model loads.

Which backend should I pick?
Auto
Let Lemonade choose the best one for your computer. This is the right answer for almost everyone.
CUDA
For NVIDIA graphics cards. The fastest option if you have one.
ROCm
For AMD graphics cards. Fast, but supports fewer cards than Vulkan.
Vulkan
Works on almost any graphics card (NVIDIA, AMD and Intel). A good choice when CUDA or ROCm isn't an option. It can be a little slower.
CPU
Uses the main processor. Works on any computer but is the slowest, so it suits small models.

A green dot means installed. “Update needed” means Lemonade has a newer build for that backend.
