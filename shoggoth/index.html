Watch your graphics memory fill as models load. If you have more than one card, choose which ones Shoggoth uses and in what order. Changes apply the next time a model loads.

Each machine at the back is one graphics card. Its lights show how hard it's working. The beaker shows memory used across all your cards. The gauge shows the hottest card. The coil sparks as the cards work harder, and the radio has a meter for each one.

Engine

An engine is a program that runs models. Shoggoth picks one for each model, starts it, and frees its memory when you switch. You don't need this page to chat. It's here if you want to look under the bonnet.

Lemonade runs several kinds of model (chat, speech, pictures and more), and each kind can run on different hardware, called a backend. Pick the one you want, or install one that's missing. Changes apply the next time a model loads.

Which backend should I pick?
Auto
Let Lemonade choose the best one for your computer. This is the right answer for almost everyone.
CUDA
For NVIDIA graphics cards. The fastest option if you have one.
ROCm
For AMD graphics cards. Fast, but supports fewer cards than Vulkan.
Vulkan
Works on almost any graphics card (NVIDIA, AMD and Intel). A good choice when CUDA or ROCm isn't an option. It can be a little slower.
CPU
Uses the main processor. Works on any computer but is the slowest, so it suits small models.

A green dot means installed. “Update needed” means Lemonade has a newer build for that backend.
